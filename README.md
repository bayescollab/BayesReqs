# BayesReqs

Base build requirements for the [BayesShip](https://github.com/bayescollab/BayesShip) code and its derivatives. It can be built from source in an Ubuntu environment by cloning this repository (perhaps within `/usr/local`) and running the following inside of it:
```shell
# Install requirements
./apt-installs.sh
# Install ADOL-C
./adolc-install.sh
```
